Conncepts Learnt: 
1) sort: used to sort the lines of a text file 
2) uniq: it is used to omit or report repeated line. But, when it is used with the flag "-u", it helps us to find out 
   the unique lines in a text file. 
3) Piping( " | "): It is used to connect the standard output of one command to the standar input of another command. 
   In the command "cat data.txt | sort | uniq -u", the output of "cat data.txt" is given as input to the sort command. 
   Subsequently, the output of sort command is given to uniq -u as input, and the output of "uniq -u" command 
   is given as the final output.
