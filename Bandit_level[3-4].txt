Concepts Learnt: 
1) Hidden files in Linux: In its early days, the ls command used to display "." and ".." which are hardlinks used to refer to the current and  
   the parent directory. Hardlinks are a second name for the exact some file or directory. The programmers started feeling annoyed to see "." 
   and ".." pop up every time the "ls" command was executed. Therefore, they found a coding solution to this and programmed the "ls" command to
   ignore the files named "." and "..". This causes the linux system to ignore any filename beginning with ".". Thus, the files whose names begin 
   with "." are hidden in the linux operating system. 
2) The "-a" flag with ls command: The "-a" flag used in "ls -a" command directs the system to display all the files including those starting with 
   "." (hidden files).
