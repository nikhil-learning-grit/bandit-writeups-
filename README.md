OVERTHEWIRE BANDIT WRITE-UPS 

This repository contains the writeups of all the levels that I have completed on overthewire bandit. It will include my approach and the details about the commands that I learnt. 
OverTheWire Bandit is a popular, free wargame designed for absolute beginners to learn Linux command-line basics and essential cybersecurity concepts.
(Link: https://overthewire.org/wargames/bandit/) 

The aim of creating this repository is to: 
1) Get a deeper understanding of the Linux Commands used in this wargame 
2) Build and enhance my technical writing skills
3) Document my learning process
