Objective: The objective of this level is to retrieve the password from a file named "--spaces in the file name--" in 
the home directory. 

Steps Taken: 
Step 1: Login to Level 2 with the help of the username (bandit2) and password retrieved in the previous
        level, via the ssh command. 
        Command Used: ssh bandit2@bandit.labs.overthewire.org -p 2220
Step 2: Print the contents of the file named "--spaces in the file name--" using the cat command.
        Command used: cat ./--spaces\ in\ the\ file\ name-- or cat "./--spaces in the file name--" 

Commands used: 
1) ssh 
2) cat 

Concepts learnt: 
1) For a file having spaces in its name, the comands such as cat, touch etc. are used with backslash as shown in the Step 2. 
   The filename can be written in this format fast and automatically by writing first 2 or 3 letters of the file followed by
   pressing tabspace.
2) Alternatively, the whole file name (if containing any spaces) can be put into quotes, to execute the command (cat, touch etc.)
   efficiently.
